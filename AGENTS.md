# Правила работы с репозиторием

После завершения каждой задачи:

1. Проверь внесённые изменения.
2. Выполни `git add -A`.
3. Создай git commit с кратким осмысленным сообщением.
4. Выполни `git push origin HEAD`.

Делай commit и push автоматически после каждой успешно выполненной задачи, если пользователь явно не сказал обратное.
